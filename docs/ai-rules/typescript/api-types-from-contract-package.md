# Backend types from the contract package

TypeScript modules should use the same API type rules as the rest of the repo: derive shapes from
`@kacper-ksiazek/ord-api-types` and re-export through feature `types/` barrels.

Full examples and Good/Bad patterns: [`api-design/api-types-from-generated-schema.md`](../api-design/api-types-from-generated-schema.md).
